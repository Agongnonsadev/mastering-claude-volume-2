# Records of the French edition's runs

These files are the records of the trials described in the book, run on October 20, 2026 with the code, the prompts and the cases of the French edition. They are kept as they were measured: the answers of Claude and the grading reasons are in French. Only the column names and the case IDs follow the English code, so that its scripts can read them (`--regrade`). The case `french` was, in the French run, the case `anglais`: a question in English, to a prompt that asked for answers in French.

Your own runs, with the English code, will overwrite these files.
