# Records of the French edition's runs

These files are the records of the three `claude -p` trials described in the book (step 7), run on October 21, 2026 with the server, the requests and the database of the French edition. They are kept as they were measured: the requests and Claude's answers are in French, and the tool names in Claude Code's output are those of the French server (`mcp__comptoir__appliquer_correction` for `apply_correction`, `bilan_du_soir` for `evening_review`). Only the file names and the keys written by the script (`request`, `gaps`, `output`) follow the English code; the `output` field is Claude Code's JSON output, unchanged.

Your own runs, with the English code, will add their files next to these.
