# Records of the French edition's runs

These files are the records of the trials described in the book, run on October 20, 2026 with the code, the prompts and the messages of the French edition. They are kept as they were measured: the answers of Claude and the router's reasons are in French. Only the column names, the message IDs, the categories, the modes and the settings follow the English code. The message `pickup-french` was, in the French run, the message `retrait-anglais`: a question in English, to a Comptoir that answered in French.

Your own runs, with the English code, will overwrite these files.
